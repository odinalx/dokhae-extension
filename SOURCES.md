# Building Dokhae from source (for add-on reviewers)

The Firefox package is built from this source with [WXT](https://wxt.dev) and
Vite. The same source also builds the Chrome package; nothing here is
generated by hand.

## Requirements

- Node.js 20 or newer, npm 10 or newer
- Linux, macOS or Windows; network access during `npm ci`

## Steps

```sh
npm ci
WXT_SITE_URL=https://dokhae.fr npx wxt build -b firefox
```

The unpacked extension is then in `.output/firefox-mv3/`, identical to the
submitted package. (`WXT_SITE_URL=https://dokhae.fr npm run zip` builds both
browsers and writes the zips to `.output/`.)

## Third-party files

`npm ci` runs `scripts/copy-assets.mjs`, which puts the OCR engine in
`public/tesseract/`:

- `worker.min.js`, copied unchanged from the `tesseract.js` npm package (5.x),
- `tesseract-core-lstm.wasm.js` and `tesseract-core-simd-lstm.wasm.js`,
  copied unchanged from the `tesseract.js-core` npm package,
- `kor.traineddata.gz`, the Korean model, downloaded from
  `https://tessdata.projectnaptha.com/4.0.0_best/kor.traineddata.gz`.

These are not minified by us. Text recognition runs locally with them; the
`Function` constructor that the linter reports lives in that upstream code.

## What the extension sends

- To `https://dokhae.fr` (the extension's own service): the account token and
  the Korean text read from a bubble or selected by the user, for analysis.
- To `ko.dict.naver.com`, `dict-dn.pstatic.net` and `translate.google.com`:
  the word or sentence the user asks to hear, to fetch its pronunciation.
- To `127.0.0.1:8765` / `localhost:8765`: flashcards, only if the user picks
  Anki (AnkiConnect) as destination.

Screenshots of the tab are cropped and read locally; the image never leaves
the browser.
